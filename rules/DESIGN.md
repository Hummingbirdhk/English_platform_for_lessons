# Design Rules

Use Ant Design as the UI foundation. The visual system should be clean, modern, readable, friendly, and suitable for children/teenagers without becoming childish.

Keep lesson content as the visual focus. Prefer cards, clear spacing, short blocks, large enough type, obvious interactive states, and responsive layouts.

Avoid visual overload, excessive animation, too many accent colours, tiny text, giant text walls, and dashboard-like complexity.

Correct/incorrect feedback must be unmistakable and should not rely on colour alone.
