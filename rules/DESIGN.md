# Design Rules

Use Ant Design as the UI foundation. The visual system should be clean, modern, readable, friendly, and suitable for children/teenagers without becoming childish.

## Product layout

Use one consistent application shell with clear access to:

- Home
- Materials
- Lessons
- Students

The Materials and Lessons libraries may use cards, search and filters. Student-facing material detail pages should feel editorial and focused on learning rather than like an admin dashboard.

## Visual hierarchy

- use a light neutral page background and white content surfaces;
- keep one restrained primary accent through the Ant Design theme;
- use generous spacing between learning blocks;
- keep body copy comfortably readable at approximately 16px or larger;
- use rounded cards consistently rather than inventing new shapes per feature;
- keep metadata secondary to the material title and learning content;
- make active navigation and interactive states obvious;
- keep layouts responsive from mobile to desktop.

## Learning blocks

Prefer short cards and sections for grammar, vocabulary, reading and video.

Vocabulary cards should make the term, translation and example easy to scan. If an image is available, it supports the word rather than dominating the page.

Reading material should use comfortable line length and generous line height.

Video should stay inside a responsive 16:9 frame with pre-watch and post-watch tasks nearby.

## Avoid

- visual overload;
- excessive animation;
- too many accent colours;
- tiny text;
- giant text walls;
- decorative clutter;
- complicated navigation;
- dense admin tables for the first version;
- inconsistent button/card styles.

Correct/incorrect feedback must be unmistakable and should not rely on colour alone.
