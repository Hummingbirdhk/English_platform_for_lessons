# Lesson Structure

A lesson is a curated sequence built from reusable materials and interactive exercises.

Do not duplicate a reusable grammar explanation, vocabulary set, reading text or video directly inside a lesson when an existing material can be referenced by ID.

A lesson may include:

- warm-up or topic introduction;
- vocabulary material;
- vocabulary practice;
- grammar material;
- controlled grammar practice;
- reading material;
- listening/video material;
- speaking prompts;
- interactive exercises;
- revision;
- final task;
- homework.

Not every lesson needs every block. Each section must have a teaching purpose.

Prefer a progression from understanding to active use:

```text
context → vocabulary → explanation → controlled practice → receptive skill → production
```

This is a guideline, not a rigid template. Reorder blocks when the teaching objective requires it.

Keep instructions short and clear. Reuse previously learned vocabulary and grammar whenever useful.
